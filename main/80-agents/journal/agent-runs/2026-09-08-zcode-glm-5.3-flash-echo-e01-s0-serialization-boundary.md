# Agent Run — 2026-09-08-zcode-glm-5.3-flash-echo-e01-s0-serialization-boundary

## Trabajo

- **Objetivo:** cerrar el boundary `valor Go → encoding/json → C()` en el pre-walk UTF-8 de `Canonicalize`, que reconocía `json.Marshaler` sólo cuando el kind era `Struct`.
- **Alcance atribuible a esta combinación superficie×modelo:** diseño del espejo de `newTypeEncoder` (Marshaler > TextMarshaler, pointer receivers sólo con `CanAddr()`, method sets promovidos de embebidos), promoción de campos exportados de structs embebidos no exportados, caso Array; batería de 13 tests con `MarshalJSON`/`MarshalText` reales.
- **Artefactos afectados:** `xKoRx/echo` `v3/sdk/contracts/wire/canonicalize.go` y `canonicalize_test.go` (commit `aafa2f62`, parent `6cf39edf`, publicado fast-forward a `origin/master`).

## Evidencia

- **Validaciones ejecutadas:** `GOWORK=off go test ./...` PASS; `go test -race -cover ./...` PASS (contracts 95.1%, wire 97.0%, fakeconsumer 95.5%); `go vet` PASS; gofmt limpio. Semántica stdlib verificada con programas de prueba desechables contra go1.25.5 (`newTypeEncoder`, `condAddrEncoder`, `typeFields`, `resolveKeyName`, `appendCompact`, `appendString`).
- **Resultado observable:** Marshaler value/pointer receiver, nil pointer, salida JSON inválida, salida con UTF-8 inválido, TextMarshaler (valores, pointer receivers, map keys, `time.Time`), promoción de embebidos, arrays, `[]byte` base64, `RawMessage`, ciclos y referencias compartidas: todos cubiertos por tests nominales en `canonicalize_test.go`.
- **Limitaciones de la evidencia:** resolución de sombras/ambigüedad de nombres de typeFields (BFS por profundidad) no se espeja; el walk sobre-recorre en ese caso patológico y falla del lado seguro (rechazo en vez de U+FFFD silencioso).
