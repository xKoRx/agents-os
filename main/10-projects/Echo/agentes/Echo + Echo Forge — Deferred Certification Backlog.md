# Echo + Echo Forge — Deferred Certification Backlog

## Propósito

Mantener en un carril único, ordenado y no ejecutado las certificaciones físicas y cross-lane que quedaron fuera del critical path de desarrollo de Echo/Echo Forge.

## Contenido

### Decisión de gestión congelada

La certificación física/de infraestructura se retira temporalmente del critical path de desarrollo mientras se construye el Aranea MCP Access Plane; no se waiva. `IMPLEMENTED != CERTIFIED`. No se cambia ningún contrato frozen, no se inventa evidencia y no se marcan PASS T2.11, T2.12 ni T2.13.

### Taxonomía de estado

| Estado | Significado | Evidencia mínima |
|---|---|---|
| PLANNED | Trabajo definido, no ejecutado | alcance y dependencias |
| IMPLEMENTED | Código/configuración materialmente implementado | diff y tests del scope |
| SOURCE VERIFIED | Fuente y contratos verificados | revisión/gates source |
| RELEASED | Artefacto publicado desde SHA autorizado | manifest y digest |
| DEPLOYED | Runtime objetivo ejecuta el artefacto autorizado | deployment proof |
| PHYSICALLY CERTIFIED | Receta real ejecutada sobre runtime físico | evidencia durable end-to-end |
| CROSS-LANE CERTIFIED | Handoff real aceptado por el lane consumidor | receipt y read-back |
| CLOSED | Todos los estados requeridos por la fase están satisfechos | veredicto final y referencias |

Los estados son dimensiones de evidencia; `CLOSED` nunca se deriva de `IMPLEMENTED` o `RELEASED` por sí solos.

### Delta de corrección source CERT-F04-01 encoding — 2026-09-17 (misión NORMAL F05C-CERT-F04-01-C3; fix de source; veredicto `SOURCE FIX PASS`)

Corrigió en source el segundo defecto de la release `0.2.99` demostrado por el run físico RERUN (`cert-f04-01-rerun-20260917T211613Z-0997458c`, Campaign `a470e565-…`, FlowRun `efc4ac0c-…`, StrategyRef `4b86cd72-…`, magic `26090011004`): compile child SUCCESS en primer intento (MetaEditor `0 errors, 1 warnings`, EX5 176730 B, log 15984 B durables) pero `mt5_compile_persist_v1` falló `CONTRACT_CONFLICT / artifact_integrity: compile log does not report 0 errors` → Campaign/FlowRun `FAILED`, sin EvaluationRefs/StrategyVersion/HandoffManifest. **Root cause verificada en source @ `49fce32`:** dos gates tomaban decisiones distintas sobre el mismo resultado — `ArtifactCompiler.evaluateCompileArtifacts` matcheaba `compileSuccessPattern` sobre `normalizeCompileLog(data)` (UTF-16LE/BE con BOM decodificado) mientras `VerifyCompiledArtifactForSeal` matcheaba sobre los bytes crudos del log UTF-16LE descargado; los tests Core usaban sólo fixtures UTF-8, invisibilizando el mismatch. **Fix (criterio único compartido, `MIGRATION: NONE`):** nueva función pura `CompileLogReportsZeroErrors(raw []byte) bool` en `sqx/core/capabilities/strategy_version.go` como única autoridad de interpretación de compile logs (UTF-8; UTF-16LE con BOM `FF FE`; UTF-16BE con BOM `FE FF`; patrón contractual intacto `(?i)Result:\s*0 errors`); fail-closed estricto para evidencia inválida — log ausente/vacío, payload UTF-16 impar (sin truncamiento silencioso del byte final) y surrogates sin pareja se rechazan en vez de producir PASS falso (mejora sobre el normalizador previo del adapter, que truncaba); ambos gates (compiler y seal) invocan exactamente esa función y el parser duplicado del adapter (`compileSuccessPattern` local + `normalizeCompileLog` + helpers UTF-16) fue eliminado. Los bytes originales del objeto durable nunca se modifican: la decodificación es sólo interpretación textual, sin reescritura de key/size/SHA256/evidencia; MQ5/EX5/result status/Primary/Evidence/durable refs siguen validándose igual.
